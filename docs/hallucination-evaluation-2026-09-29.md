## ข้อสรุป

ในชุดคำถามเดิม **ไม่พบคำตอบที่ LLM judge ระบุว่าไม่มีหลักฐาน (0/36)** และคำถามที่ไม่มีคำตอบถูกปฏิเสธครบ **11/11** แต่ **ยังสรุปอัตรา hallucination จริงเป็น 0% ไม่ได้**: ทีมบันทึกไว้ว่า gemma3 judge เคยปล่อยคำตอบแต่ง 2 ข้อ, ยังไม่มี gold set ที่คนตรวจ, และรอบนี้ไม่ได้สร้างคำตอบใหม่จาก Luna/Local บนข้อมูลล่าสุด

การทดสอบสดด้วย Luna ถูกระบบอนุมัติอัตโนมัติปฏิเสธ เพราะจะส่ง context จากคลังความรู้ของโปรเจกต์ไป API ภายนอก จึงไม่ได้เรียก API ในรอบนี้ ส่วน Ollama ในเครื่องไม่พร้อมใช้งาน การประเมิน end-to-end สดต้องรันภายใต้สภาพแวดล้อมที่อนุญาตและมีโมเดลพร้อม

## งานต่อที่มีผลต่อคะแนน rubric

1. ให้คนตรวจคำตอบและ context 20–30 ข้อแบบไม่เห็นคะแนน judge ก่อน แล้ววัดอัตราที่คนกับ judge เห็นตรงกัน
2. ทำ red-team: prompt injection, ขอข้อมูลผู้ใช้อื่น, ถามเรื่องใกล้เคียงแต่เอกสารไม่ตอบ และขอให้อ้างอิงแหล่งปลอม
3. ทดสอบ API/Local บนคำถามชุดเดียวกันอย่างน้อย 3 รอบ แยก `unsupported`, `wrong citation`, `off-question`, `false refusal` และเวลา
4. แก้ Q30 ด้วยการคัดตารางตัวเลขที่ไม่ใช่เนื้อหาความรู้ออกจาก index หรือเพิ่มเงื่อนไขว่าหลักฐานต้องตอบประเด็นคำถามจริง
